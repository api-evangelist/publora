## API Endpoints

- [Create Post](https://docs.publora.com/endpoints/create-post): `POST /api/v1/create-post`
- [Get Post](https://docs.publora.com/endpoints/get-post): `GET /api/v1/get-post/:postGroupId`
- [List Posts](https://docs.publora.com/endpoints/list-posts): `GET /api/v1/list-posts`
- [Update Post](https://docs.publora.com/endpoints/update-post): `PUT /api/v1/update-post/:postGroupId`
- [Delete Post](https://docs.publora.com/endpoints/delete-post): `DELETE /api/v1/delete-post/:postGroupId`
- [Upload Media](https://docs.publora.com/endpoints/upload-media): `POST /api/v1/get-upload-url`
- [Platform Connections](https://docs.publora.com/endpoints/platform-connections): `GET /api/v1/platform-connections`
- [Test Connection](https://docs.publora.com/endpoints/test-connection): `POST /api/v1/test-connection/:platformId`
- [Post Logs](https://docs.publora.com/endpoints/post-logs): `GET /api/v1/post-logs/:postGroupId`
- [Webhooks](https://docs.publora.com/endpoints/webhooks): `POST/GET/PATCH/DELETE /api/v1/webhooks`
- [LinkedIn Post Statistics](https://docs.publora.com/endpoints/linkedin-statistics): `POST /api/v1/linkedin-post-statistics`
- [LinkedIn Account Statistics](https://docs.publora.com/endpoints/linkedin-statistics): `POST /api/v1/linkedin-account-statistics`
- [LinkedIn Reactions](https://docs.publora.com/endpoints/linkedin-reactions): `POST/DELETE /api/v1/linkedin-reactions`
- [LinkedIn Comments](https://docs.publora.com/endpoints/linkedin-comments): `POST/DELETE /api/v1/linkedin-comments`
- [LinkedIn Followers](https://docs.publora.com/endpoints/linkedin-followers): `POST /api/v1/linkedin-followers`
- [LinkedIn Profile Summary](https://docs.publora.com/endpoints/linkedin-profile-summary): `POST /api/v1/linkedin-profile-summary`

### Workspace / B2B Endpoints

- [Workspace Guide](https://docs.publora.com/guides/workspace): Managed users, API key generation, white-label
- `GET /api/v1/workspace/users` — List managed users
- `POST /api/v1/workspace/users` — Create managed user
- `DELETE /api/v1/workspace/users/:userId` — Detach managed user
- `POST /api/v1/workspace/connection-url` — Generate connection URL for user
- `POST /api/v1/workspace/api-key` — Generate API key for managed user
